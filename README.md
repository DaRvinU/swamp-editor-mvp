# 🐸 SwampEditor/AI-ассистент проверки новостей

**Команда:** Source? Trust Me Bro  

## 📌 О проекте
SwampEditor - это MVP AI-платформы, которая помогает новостным редакциям проверять материалы перед публикацией. 
В текущей версии реализован **демо-режим** (умная заглушка, имитирующая работу AI), а также полноценное сохранение истории проверок в облачную базу данных.

## ✨ Что уже умеет MVP
- **Проверка текста:** принимает черновик новости и подсвечивает потенциальные проблемы (цифры, категоричные утверждения, даты).
- **Наглядный отчет:** показывает карточки с метками ✅ (подтверждено), ⚠️ (нет источника), ❌ (противоречит).
- **Сохранение истории:** каждая проверка автоматически сохраняется в облачную базу данных Firebase Firestore и отображается в блоке «Последние проверки».
- MVP развёрнут на Streamlit Community Cloud: https://swamp-editor-mvp-akdhfjjh5no4fuuwujjecm.streamlit.app/

## 🛠 Технологии
- **Frontend/Backend:** Python, Streamlit
- **База данных:** Firebase Firestore (NoSQL)
