## О проекте

SwampEditor — концепция AI-платформы для помощи новостным редакциям. Она должна помогать проверять материалы до публикации и отслеживать изменения в уже опубликованных новостях.

Решение рассматривается в контексте задачи News Media Holding: ускорить первичную обработку информационного потока и помочь редакторам уделять больше внимания проверке фактов.

**Важно:** текущая версия — ранний демонстрационный прототип, а не готовый инструмент для редакционного использования. Она показывает работу связки AI, поиска источников и облачного хранения, но может ошибаться и не заменяет редактора.

## Что реализовано в MVP

Пользователь вводит текст новости. Прототип:

1. Разбивает текст на предложения, рассматриваемые как проверяемые утверждения.
2. Ищет материалы по каждому утверждению с помощью веб-поиска.
3. Передаёт утверждение и фрагменты найденных материалов в GigaChat.
4. Показывает предварительный статус:
 - `✅ Подтверждено` — найденные материалы, по оценке модели, поддерживают утверждение;
 - `❌ Противоречит` — найденные материалы, по оценке модели, ему противоречат;
 - `⚠️ Нет источника` — подходящих подтверждений недостаточно или их не удалось найти.
5. Показывает найденные материалы и ссылки на них.
6. Сохраняет историю проверок в Firebase Firestore, если база подключена.

Если GigaChat недоступен, приложение может перейти в демо-режим. Результаты этого режима **не являются AI-анализом и не должны восприниматься как фактчекинг**.

## Ограничения и известные риски

MVP предназначен для демонстрации идеи и проверки технического сценария. Он не должен использоваться как единственное основание для публикации или опровержения новости.

- Модель может принять совпадение по человеку или теме за подтверждение конкретного события. Например, упоминание другой награды не доказывает получение «Оскара».
- Найденный фрагмент может быть неполным, устаревшим или относиться к похожему, но другому событию.
- Поиск может вернуть сайты с разным уровнем надёжности, включая пользовательские видео и публикации.
- Поисковая выдача зависит от внешнего сервиса и может не содержать нужных материалов.
- Результат может отличаться при повторном запуске.
- Свежие события могут ещё не попасть в поисковый индекс.
- При ошибке API или исчерпании лимита GigaChat анализ может перейти в демо-режим либо стать временно недоступным.
- Статус `confirmed` не означает, что факт независимо доказан: редактору нужно открыть источник и проверить контекст.

**Не вводите в демо персональные, конфиденциальные или неопубликованные данные.** Текст передаётся внешним сервисам для обработки.

## Концепция развития продукта

В полной версии SwampEditor планируется развивать следующие функции:

- приоритизация официальных источников и проверенных редакцией медиа;
- поиск и выделение первоисточников, обнаружение перепечаток;
- сопоставление конкретных деталей: кто, что сделал, где и когда;
- работа с полными текстами публикаций, а не только поисковыми фрагментами;
- запрос цитаты или фрагмента, подтверждающего каждый вывод;
- мониторинг обновлений и опровержений после публикации;
- история развития события — концепция **News Time Machine**;
- предложения по исправлению и обновлению материала с сохранением решения за редактором.

Эти функции описывают направление развития продукта и **не все реализованы в текущем MVP**.
