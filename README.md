## 📌 О проекте

**SwampEditor** — это AI-платформа, которая помогает редакторам проверять новости перед публикацией. 
Современные AI-инструменты ускорили *создание* новостей в 2,5 раза, но процесс *редакторской проверки* остался прежним. SwampEditor берет на себя рутину: фактчекинг, поиск первоисточников и выявление противоречий, оставляя финальное решение за человеком.

**Главная ценность:** Ускорить этап проверки, снизить нагрузку на редакторов и обеспечить актуальность публикаций.

## ✨ Что умеет текущая версия (MVP)

*   **Умная разбивка текста:** Система разбивает новость на отдельные предложения (утверждения). Слишком короткие фразы отбрасываются, чтобы не тратить ресурсы на поиск.
*   **Поиск реальных источников:** По каждому утверждению выполняется поиск в интернете (через DuckDuckGo). Используются укороченные запросы и защита от лимитов API, чтобы выдача была релевантной.
*   **Глубокий фактчекинг:** GigaChat сравнивает текст новости с найденными фрагментами источников по жесткому алгоритму. Он проверяет даты, места, числа и участников событий. 
*   **Понятные статусы:** Каждому утверждению присваивается один из трех статусов:
    *   `✅ Подтверждено` — факт совпадает с источником.
    *   `❌ Противоречит` — источник указывает на другие детали (другая дата, другое место, другое число).
    *   `⚠️ Нет источника` — в найденных материалах нет информации об этом событии.
*   **Общий вердикт:** В зависимости от результатов проверки всех предложений, система выводит общий вывод по всей новости (можно ли ее публиковать или нужна доработка).
*   **Сохранение истории:** Все проверки сохраняются в облачную базу данных Firebase и отображаются в блоке «Последние проверки».
*   **Отказоустойчивость:** Если AI-модель недоступна, система автоматически переключается на «умную заглушку», чтобы демонстрация продукта никогда не ломалась.

## 🛠 Технический стек

*   **Frontend / Backend:** Python, Streamlit.
*   **LLM (Искусственный интеллект):** GigaChat API (модель `GigaChat-2`).
*   **Поиск источников:** DuckDuckGo Search (через библиотеки `ddgs` или `duckduckgo_search`).
*   **База данных (NoSQL):** Firebase Firestore (Google Cloud).
*   **Валидация данных:** `json-repair`, `pydantic`.
*   **Хостинг:** Streamlit Community Cloud.

## 🏗 Архитектура и пайплайн

Приложение работает по следующему пайплайну:
1. Пользователь вставляет текст новости в интерфейс.
2. Скрипт разбивает текст на предложения (`extract_claims`), отбрасывая короткие фразы.
3. Для каждого предложения выполняется поиск в интернете (`search_evidence`). Берутся первые 15 слов предложения, чтобы выдача была точной.
4. GigaChat получает список утверждений и найденные фрагменты источников (`verify_claims`). Модель строго следует инструкции: сравнивает даты, места и детали, чтобы отличить `confirmed` от `contradicted`.
5. Полученные данные сохраняются в Firebase.
6. Интерфейс отрисовывает карточки с результатами, ссылки на реальные источники и общий вердикт.

**Схема документа в Firebase (коллекция `checks`):**
```json
{
  "text": "Исходный текст новости...",
  "created_at": "2026-10-27 21:00",
  "results": [
    {
      "claim": "Мэр заявил, что бюджет вырос на 40%",
      "status": "contradicted",
      "comment": "Источник указывает, что бюджет вырос только на 12%.",
      "url": "https://rbc.ru/...",
      "search_url": "https://yandex.ru/search/?text=..."
    }
  ]
}
