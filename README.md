## 📌 О проекте

**SwampEditor** — это единая AI-платформа, которая помогает редакторам проверять новости перед публикацией. 
Современные AI-инструменты ускорили *создание* новостей в 2,5 раза, но процесс *редакторской проверки* остался прежним. SwampEditor берет на себя рутину: фактчекинг, поиск первоисточников и выявление противоречий, оставляя финальное решение за человеком.

**Главная ценность:** Ускорить этап проверки, снизить нагрузку на редакторов и обеспечить актуальность публикаций.

---

## ✨ Что умеет текущая версия (MVP)

*   **Фактчекинг текста:** AI вычленяет из черновика проверяемые утверждения (цифры, даты, события) и присваивает им статусы:
    *   `✅ Подтверждено` (факт верен)
    *   `⚠️ Нет источника` (требует проверки)
    *   `❌ Противоречит` (найдено расхождение)
*   **Генерация источников:** К каждому утверждению прикрепляется ссылка на источник. Если нейросеть не может найти точную ссылку, система автоматически генерирует ссылку на поисковую выдачу (Яндекс) по этому факту.
*   **Сохранение истории:** Все проверки сохраняются в облачную базу данных и отображаются в блоке «Последние проверки» (доступны после перезагрузки страницы).
*   **Отказоустойчивость:** Если AI-модель недоступна (ошибки API, лимиты), система автоматически переключается на «умную заглушку», которая эвристически анализирует текст и подставляет поисковые ссылки, чтобы демонстрация продукта никогда не ломалась.

## 🏗 Архитектура и структура данных

Приложение работает по следующему пайплайну:
1. Пользователь вставляет текст в интерфейс Streamlit.
2. Текст отправляется в GigaChat API с жестким системным промптом (запрос строгого JSON-формата).
3. Ответ парсится и очищается от возможных артефактов (markdown-оберток). Если JSON поврежден — он чинится библиотекой `json_repair`.
4. Полученные данные сохраняются в Firebase Firestore с отметкой времени (`SERVER_TIMESTAMP`).
5. Интерфейс отрисовывает карточки с результатами и обновляет историю.

**Схема документа в Firebase (коллекция `checks`):**
```json
{
  "text": "Исходный текст новости...",
  "created_at": "2026-10-27 21:00",
  "results": [
    {
      "claim": "Мэр заявил, что бюджет вырос на 40%",
      "status": "contradicted",
      "comment": "Найдено расхождение с открытыми источниками",
      "url": "https://yandex.ru/search/?text=..."
    }
  ]
}
